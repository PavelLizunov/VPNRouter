Установка (1 минута)

  1. Нажмите «Скачать APK» выше.
  2. Откройте скачанный файл. Android спросит про «Установка из неизвестных источников» — разрешите для браузера (это одноразово).
  3. Подтвердите установку и откройте приложение.

Обновления приложение проверяет само (Настройки → «Проверить обновления»). Можно поставить и через F-Droid-репозиторий — см. ссылку внизу, если он уже настроен.

Приватность

Никакой телеметрии. APK подписан; рядом с ним лежит .sha256 для проверки целостности. Подробности — PRIVACY.md.
