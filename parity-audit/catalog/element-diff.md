## Caveats

1. **Signature matching is coarse**: matches by `type::token` where token
   is the visible text or `{Binding L_X}` localization key. An element
   with literal text on one platform and a binding on the other will
   show as divergent even if the rendered string is identical.
2. **Layout containers** (Border/Grid/StackPanel without a name or text)
   are filtered out of the only-on-X lists to reduce noise. The summary
   table still counts them.
3. **Android `_Unknown_` bucket** holds elements created in shared helper
   methods (e.g. `WrapSection`, `BuildProfileChip` reused across overlays).
   Manually inspect `android-elements.json` if a page count looks low.
4. **Telegram is desktop-only by design** (Win-only Telegram WebSocket
   proxy) -- divergence here is expected, not a finding.
5. **AutoUpdate banner is Android-only** (Win uses Squirrel installer
   notify) -- divergence here is expected.
