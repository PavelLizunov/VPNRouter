Virtual Penguin Network

v2.0.0 — Installation Guide

1

Перетащи приложение

Перетащи VPNRouter.app в папку Applications

2

Открой Terminal

Нажми на иконку Terminal в этом окне

3

Вставь команду

Скопируй команду ниже (кнопка Копировать) и вставь в Terminal (Cmd+V), нажми Enter

xattr -cr /Applications/VPNRouter.app && USER=$(whoami) && sudo bash -c "echo \"$USER ALL=(root) NOPASSWD: /Users/$USER/Library/Application\\ Support/VPNRouter/bin/sing-box *\" > /etc/sudoers.d/vpnrouter && echo \"$USER ALL=(root) NOPASSWD: /usr/bin/pkill\" >> /etc/sudoers.d/vpnrouter && chmod 0440 /etc/sudoers.d/vpnrouter" && open /Applications/VPNRouter.app
4

Введи пароль Mac

Terminal попросит пароль — введи пароль от Mac. Это нужно один раз, больше не попросит.

✅ Готово! Приложение запустится. В следующий раз просто открывай из Applications.
