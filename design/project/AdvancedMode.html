Advanced mode · исправления по списку

Все 7 Advanced-страниц + меню «⋯» переверстаны по дизайн-системе.

Что общее для всех экранов (применяется к каждой странице ниже)

  • Компактный header: [28px лого] [имя + бейджи] [◂ Simple] [⋯]. Версия/билд/by — ушли в меню «О приложении». Бейджи VPN·Zapret·TG — одинаковые в обоих режимах: состояние + клик = навигация в соответствующий раздел. Статус также дублируется в footer для быстрого взгляда.
  • Единый footer: один status-bar внизу (точка · описание · компактная кнопка Stop справа). Нет двойной «Остановить VPN» на всю ширину. Нет глобального «Автозапуск с Windows» — это настройка живёт в Настройках → Автозапуск.
  • Таб-бар скроллится горизонтально вместо обрезки «Free».
  • Selection color во всех списках — accent-bg-subtle (светло-arctic), не бирюзово-зелёный.
  • Все primary action’ы — --accent-solid Arctic. Никаких фиолетовых/зелёных full-width CTA.
