# VPNRouter ChatGPT Context Pack

This folder is made to upload into a ChatGPT Project.

Recommended upload order:

1. `CHATGPT_PROJECT_INSTRUCTIONS.md`
2. `VPNROUTER_CONTEXT.md`
3. `CURRENT_INVESTIGATIONS.md`
4. `LIBRARY_DOCS.md`
5. `SCREENSHOTS.md`
6. Everything in `screenshots/`

Use `CHATGPT_PROJECT_INSTRUCTIONS.md` as the project instructions if possible. The other files can be attached as project knowledge. See `CONTEXT_PACK_GUIDE.md` for why these are Markdown files and how to keep the pack fresh.

What is included:

- Real app smoke screenshot from v2.46.0-r35.
- Headless screenshots of the main Avalonia pages.
- Stable product context: modes, routing semantics, local-network invariant, True Split, UI map, and UX principles.
- Separate active troubleshooting notes for Roblox, Discord, and True Split.
- Curated documentation links for the libraries and upstream tools VPNRouter uses.

What is intentionally not included:

- Credentials.
- Local handoff files.
- Full repo source.
- Generated logs with private user paths.
