## 1. Цель

Снизить след модели в контексте (model-context footprint) и реальную кодовую
поверхность (real code surface) **без удаления поведения или истории**.

Принципы:

- Никогда не удалять тесты или историю ради того, чтобы «вписаться» в модель.

- Контекст экономить представлением (профили/извлечение), а не удалением из репозитория.

## 5. Контекстная стратегия

- Никогда не удалять тесты / историю ради соответствия модели.
- Огульный `.qwenignore` для tests / plans **ОТКЛОНЁН** для обычной разработки.
- Установленный Qwen Code нативно поддерживает `.qwenignore` и отрицания (negation),
  однако использовать поиск-ориентированное многоуровневое извлечение по требованию
  (search-driven tiered / on-demand retrieval):
  - **Tier 0** — инструкции / текущий ledger / метаданные проекта.
  - **Tier 1** — ядро продукта; индексируется и извлекается по зонам.
  - **Tier 2** — релевантные тесты, по требованию.
  - **Tier 3** — история / дизайн / доказательства, только для провенанса.
- Выделенный профиль контекста для whole-review может исключать исторические
  plans / evidence / design и массовые тесты, **сохраняя их поисковыми** вне этого
  профиля.
- Оценка: дефолтный бандл ≈ **0.85–1.0M** токенов; ≈ **3.2–3.4M** токенов не
  загружается; **нулевое изменение рантайма**.
