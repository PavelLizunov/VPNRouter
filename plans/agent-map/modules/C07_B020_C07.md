> **TL;DR:** Core `SingBoxManager` (Module C07) orchestrates the external `sing-box` daemon across Windows, Linux, and macOS, managing process execution, Clash REST API hot-reloading (`PUT /configs?force=true`), atomic TUN ownership mutual exclusion (`TunOwnershipLock`), Windows Wintun PnP teardown/settle queues, Unix `pidfd` and polkit/sudo termination, and bounded crash diagnostics. The audit identified a critical defect where `IsHealthy()` unconditionally returns `false` on Linux when elevated via `pkexec` (due to tracking the exited wrapper handle rather than Clash API), an `IDisposable` contract violation where failed stops revive `_disposed` to 0, unescaped JSON path interpolation in hot-reload, and synchronous `Thread.Sleep` blocks freezing caller threads.

# Exhaustive Code Inventory & Audit: Core SingBoxManager Subsystem (Module C07 / Batch B020_C07)

## 1. SUMMARY & PURPOSE

The `SingBoxManager` subsystem (`VPNRouter.Core/Services/SingBoxManager*.cs`) serves as the central lifecycle controller for the external `sing-box` proxy core. It abstracts OS-specific process spawning, kernel TUN adapter synchronization, zero-downtime hot-reload reconfiguration via the Clash REST API, Unix privilege escalation and signaling, Windows Wintun driver management, and resilient crash detection/suppression.

### Component Roles & Responsibilities

1. **`SingBoxManager.cs` (Anchor Declaration)**
   - Declares the `SingBoxState` enum (`Stopped`, `Starting`, `Running`, `Restarting`, `Failed`) and the partial `SingBoxManager` class.
   - Manages state variables, dependency injection seams (`IProcessRunner`, `IHttpClient`, `ILogger`), system-wide named TUN mutex (`TunOwnershipLock`), and static Windows PnP removal task queue (`s_pendingTunRemoval`).
   - Implements thread-safe configuration reload entry points (`ReloadConfigJson`, `TryReloadConfigJson`) and the atomic disposal pattern (`Dispose()`) with AppDomain process exit coordination.

2. **`SingBoxManager.Lifecycle.cs` (Process Lifecycle & OS Spawning)**
   - Controls process initialization (`Start`, `StartWithJson`, `StartWithJsonCore`), process termination (`Stop`, `StopInternal`), forced crash recovery (`KillWedgedForRecovery`), and process restart (`Restart`, `RestartCore`).
   - Implements Linux capability inspection via `getcap` (`HasNetCapability`) to prefer unprivileged user execution over `pkexec`.
   - Coordinates Windows pre-launch Wintun adapter cleanup and settle checks (`TunAdapterDiagnostics.PreStartCleanupAsync`, `QueueTunAdapterRemoval`, `WaitForQueuedTunAdapterRemoval`).
   - Automatically co-locates `libcronet.dll` / `libcronet.so` beside the sing-box binary (`TryColocateCronet`) for NaiveProxy support.
   - Restricts operations according to `SingBoxRuntimePolicy` (headless Linux untrusted environment rules).

3. **`SingBoxManager.CrashDetect.cs` (Exit Classification & Diagnostics)**
   - Intercepts process exit notifications (`OnProcessExited`).
   - Differentiates intentional stops and restarts from genuine crashes using `_restartInProgress`, `_stopInProgress`, and exit codes (`-1`, `137`, `143`), suppressing false `Crashed` events to prevent `HealthMonitor` restart loops.
   - Extracts the final 50 lines of `singbox.log` into `vpnrouter.log` upon failure (`LogSingBoxCrashTail`).
   - Scans a thread-safe 50-line stderr ring buffer (`DetectTunOrphanCrashSignature`) to flag Windows Wintun `ERROR_FILE_EXISTS` adapter collisions (`LastCrashWasTunOrphan`) or Linux `TUNSETIFF` permission denials (`LastCrashWasLinuxTunPermissionFailure`).

4. **`SingBoxManager.Health.cs` (Liveness & Telemetry Probing)**
   - Evaluates tunnel liveness (`IsRunning`) using the Clash REST API on macOS/Linux vs. process handle state on Windows.
   - Evaluates process health (`IsHealthy`) against a 500 MB memory working set threshold.
   - Extracts CPU usage, working set memory, and start time telemetry (`GetMetrics`) returning a `ProcessMetrics` DTO.

5. **`SingBoxManager.HotReload.cs` (Zero-Downtime Clash REST API)**
   - Provides public configuration reload wrappers (`ReloadConfig`, `TryReloadConfig`, `WriteConfigToDisk`).
   - Implements the HTTP hot-reload client (`TryHotReload`), dispatching `PUT http://{ClashApi}/configs?force=true` with optional bearer authentication (`ClashAuthHeaders`) and hard 3-second deadlines.
   - Probes Clash API liveness (`IsClashApiAlive`).

6. **`SingBoxManager.LinuxStop.cs` (Unix Process Termination & Privilege Escalation)**
   - Implements safe, targeted termination of Unix sing-box processes (`LinuxStopEscalationChain`) without shell-globbing or name-based process sweeping.
   - Validates process ownership against durable start-time ticks and binary paths (`ProcessOwnership.FindOwnedSingBox`, `InspectOwnedTarget`).
   - Executes direct unprivileged `pidfd` signaling (SIGTERM=15) via `UnixOwnedProcessSignal`.
   - Escalates via `pkexec` or `sudo -n` to an internal helper flag (`--vpnrouter-internal-signal-owned-v1`) with SIGKILL=9, or macOS exact-PID `/bin/kill -KILL -- {pid}`.

#### Lifecycle Management (`SingBoxManager.Lifecycle.cs`)
- `public void Start(SingBoxConfig config)`
  - *Contract*: Serializes `config` and forwards to `StartWithJson`.
- `public void StartWithJson(string configJson)`
  - *Contract*: Checks `EffectivePolicy.Authorize(Start)`. Locks `_lifecycleGate`, verifies `_disposed == 0`, and delegates to `StartWithJsonCore`.
- `private void StartWithJsonCore(string configJson)`
  - *Exceptions*: Throws `TunOwnershipException` if TUN mutex acquisition fails. Throws `SingBoxRuntimePolicyException` or `FileNotFoundException` if binary path is invalid.
  - *Contract*: If `State == Starting` or active handle exists, logs and ignores. If `State == Running` with dead handle, cleans up via `Stop()`. Acquires TUN ownership. Resolves executable path and assigns `ProcessOwnership.ConfiguredExePath`. Rotates logs, writes config JSON, sets `State = Starting`, and calls `LaunchProcess`. Reverts state and releases lock on failure.
- `private bool TryAcquireTunOwnership()`
  - *Contract*: Checks `_ownsTunLock`. If false, acquires `_tunLock.TryAcquireExclusive()`.
- `private void ReleaseTunOwnership()`
  - *Contract*: Releases `_tunLock`, clears `_ownsTunLock` and `_exactStopUnconfirmed`.
- `public void Stop()`
  - *Contract*: Locks `_lifecycleGate` and delegates to `StopCore()`.
- `private void StopCore()`
  - *Contract*: Clears `LastCrashWasTunOrphan` and `LastCrashWasLinuxTunPermissionFailure`, then invokes `StopInternal(releaseLock: true)`.
- `public void KillWedgedForRecovery()`
  - *Contract*: Locks `_lifecycleGate` and calls `StopInternal(releaseLock: false)`. Leaves process dead with TUN lock retained for `HealthMonitor`.
- `private void StopInternal(bool releaseLock)`
  - *Contract*: Atomic CAS on `_stopState` (0 -> 1); bails if already stopping. Sets `_stopInProgress = true`.
    - *Unix*: Verifies `_ownsTunLock`. If Linux capability mode (`!_linuxUsedPkexec`), executes exact handle `SuppressExitedEvent()`, `Kill(entireProcessTree: true)`, and waits up to 5s. If elevated (pkexec/sudo), invokes `LinuxStopEscalationChain()`.
    - *Windows*: If `_handle == null` or exited, triggers orphan adapter cleanup (`QueueTunAdapterRemoval`), waits if `releaseLock`, releases lock. If process alive, calls `SuppressExitedEvent()`, `Kill(entireProcessTree: true)`, waits up to 5s, checks `HasExited`, queues adapter removal, and waits if `releaseLock`.
    - *Finally*: Clears `_stopInProgress = false` and resets `_stopState = 0`.
- `[SupportedOSPlatform("windows")] private void QueueTunAdapterRemoval(string context)`
  - *Contract*: Appends async adapter removal (`TunAdapterDiagnostics.TryRemoveAdapterAsync`) to `s_pendingTunRemoval` under `s_tunRemovalGate`.
- `[SupportedOSPlatform("windows")] private void WaitForQueuedTunAdapterRemoval()`
  - *Contract*: Synchronously waits on `s_pendingTunRemoval`. If settle failure occurs, executes `TunAdapterDiagnostics.WaitForExactPnpRemovalSettledAsync`. Loops until removal task queue settles.
- `public void Restart()`
  - *Contract*: Authorizes with policy, locks `_lifecycleGate`, and executes `RestartCore()`.
- `private bool RestartCore()`
  - *Contract*: Checks `_disposed` and `_ownsTunLock`. Sets `State = Restarting` and `_restartInProgress = true`. Calls `StopInternal(releaseLock: false)`. Sleeps 750ms on Windows for Wintun handle release. Invokes `LaunchProcess(exePath)`. Verifies handle replacement and `State == Running`. Clears `_restartInProgress = false` in finally block.
- `private void RotateSingBoxLog()`
  - *Contract*: Checks `singbox.log` size. If > 10 MB, deletes existing `singbox.old.log` and renames current log.
- `private bool HasNetCapability(string exePath)`
  - *Contract*: Linux only. Runs `getcap <exePath>` with 2s timeout. Returns true if output contains effective `cap_net_admin` and `cap_net_bind_service`.
- `internal static bool TryColocateCronet(string singBoxExePath, string bundledDir, ILogger? logger)`
  - *Contract*: Copies `libcronet.dll` (Windows) or `libcronet.so` (Linux) from `bundledDir` to sing-box executable directory if missing or file sizes differ. Returns true if co-located; false on failure or macOS.
- `private void LaunchProcess(string exePath)`
  - *Exceptions*: Throws `InvalidOperationException` if Linux sandbox blocker is present or `pkexec` is missing.
  - *Contract*: Resets crash flags and clears stderr ring buffer under `_capturedStderrLock`. If policy permits, runs `TryColocateCronet`. On Windows, calls `WaitForQueuedTunAdapterRemoval()` and `TunAdapterDiagnostics.PreStartCleanupAsync`. Determines executable and argv:
    - *Linux*: Direct if `HasNetCapability`; otherwise `pkexec <exePath> run -c <config>`.
    - *macOS*: `/usr/bin/sudo <exePath> run -c <config>`.
    - *Windows*: `<exePath> run -c <config>`.
    - Checks `_disposed` immediately before spawn. Calls `_runner.Start(request)`. Wires `OutputLine`, `ErrorLine` (populating ring buffer), and `Exited` (invoking `OnProcessExited`). Sets `State = Running` and invokes `Started(pid)`.
- `private static string WriteJsonToDisk(string json)`
  - *Contract*: Ensures directory existence with private permissions (0700/0600 on Unix via `AppPaths`). Writes JSON to `AppPaths.CurrentConfigPath`.

#### Crash Detection (`SingBoxManager.CrashDetect.cs`)
- `private void OnProcessExited()`
  - *Contract*: Overload forwarding to `OnProcessExited(null)`.
- `private void OnProcessExited(int? eventExitCode)`
  - *Contract*: Reads exit code from event or via `_handle.WaitForExitAsync(CancellationToken.None).GetAwaiter().GetResult()`.
    - *False Crash Suppression*: If `(_restartInProgress || _stopInProgress)` AND exit code is `-1`, `137`, or `143`, logs information, captures crash tail, runs signature scan, and returns without firing `Crashed`.
    - *Genuine Crash*: Logs crash with exit code, invokes `LogSingBoxCrashTail()`, runs `DetectTunOrphanCrashSignature()`, updates `State = Failed`, invokes `Crashed` event, and on Windows calls `QueueTunAdapterRemoval`.
- `private void LogSingBoxCrashTail()`
  - *Contract*: Opens `singbox.log` with `FileShare.ReadWrite | FileShare.Delete`. Reads last 50 lines into a ring buffer and logs them into `vpnrouter.log`. Catches all exceptions.
- `private void DetectTunOrphanCrashSignature()`
  - *Contract*: Snapshots `_capturedStderr` under `_capturedStderrLock`. Scans lines:
    - *Linux*: Sets `LastCrashWasLinuxTunPermissionFailure = true` if line matches `IsLinuxTunPermissionFailure`.
    - *Windows*: Sets `LastCrashWasTunOrphan = true` if line contains `"Cannot create a file when that file already exists"`, `"configure tun interface:"`, or `"open interface take too much time to finish"`.
- `internal static bool IsLinuxTunPermissionFailure(string? line)`
  - *Contract*: Returns true if line contains both `"TUNSETIFF"` and `"operation not permitted"`.

#### Health & Telemetry (`SingBoxManager.Health.cs`)
- `public bool IsRunning()`
  - *Contract*: On macOS and Linux, returns `IsClashApiAlive()`. On Windows, returns `State == SingBoxState.Running && _handle?.HasExited == false`.
- `public bool IsHealthy()`
  - *Contract*: On macOS, returns `State == SingBoxState.Running && IsClashApiAlive()`. On other platforms, returns false if `_handle == null || _handle.HasExited`. Reads process snapshot; logs warning if working set > 500 MB; returns true if snapshot available.
- `public ProcessMetrics GetMetrics()`
  - *Contract*: Reads `_handle.TryGetSnapshot()`. Returns `ProcessMetrics` populated with memory (MB), CPU total processor time, and start time. Returns empty instance if handle is null or exited.

#### Unix Stop Implementation (`SingBoxManager.LinuxStop.cs`)
- `private bool LinuxStopEscalationChain()`
  - *Contract*: Finds owned process identity via `ProcessOwnership.FindOwnedSingBox`.
    - *Linux*: Attempts direct unprivileged `pidfd` signal 15 (SIGTERM). If process survives, checks policy (bails if restricted), resolves host helper executable, attempts `pkexec` with signal 9 (SIGKILL, 30s timeout), then falls back to `sudo -n` with signal 9 (5s timeout).
    - *macOS*: Verifies target identity; attempts `sudo -n /bin/kill -KILL -- <pid>` (5s timeout).
    - Verifies exit state via `InspectOwnedTarget`. Returns true if process is gone or replaced.
- `private bool RefuseUnknownIdentity(int pid)`
  - *Contract*: Logs error and returns false when PID identity cannot be verified.
- `private static OwnedTargetState InspectOwnedTarget(OwnedProcessIdentity expected)`
  - *Contract*: Inspects process by PID. Returns `GoneOrReplaced` if exited or replaced; `Matching` if identity matches; `IdentityUnavailable` if access/identity probe fails.
- `internal static IReadOnlyList<string> BuildLinuxOwnedSignalHelperArguments(string hostPath, OwnedProcessIdentity target, int signal, bool nonInteractiveSudo = false)`
  - *Contract*: Constructs argument list: `[-n] <hostPath> --vpnrouter-internal-signal-owned-v1 <pid> <ticks> <exePath> <signal>`.
- `internal static IReadOnlyList<string> BuildMacExactKillArguments(int pid)`
  - *Contract*: Constructs `["-n", "/bin/kill", "-KILL", "--", "<pid>"]`.
- `private static string? ResolveSignalHelperHost()`
  - *Contract*: Validates `Environment.ProcessPath`. Returns path if binary is `VPNRouter.App` or `VPNRouter.CLI`; otherwise `null`.
- `private bool TrySpawnAndWait(string fileName, IReadOnlyList<string> args, int timeoutMs, string label)`
  - *Contract*: Executes process via `_runner.RunAsync` with timeout. Returns true if exit code is 0 and did not time out.

## 3. DATA FLOWS & STATE MACHINES

### 3.1. Operational State Transitions (`SingBoxState`)

```
      ┌─────────────────────────────────────────────────────────┐
      │                                                         │
      ▼                                                         │
[ Stopped ] ──(StartWithJsonCore)──► [ Starting ]               │
     ▲                                      │                   │
     │                                      ▼                   │
     │                            (LaunchProcess OK)            │
     │                                      │                   │
     │                                      ▼                   │
     │       (StopInternal OK)        [ Running ]               │
     ├──────────────────────────────────────┤                   │
     │                                      │                   │
     │                              (RestartCore)               │
     │                                      │                   │
     │                                      ▼                   │
     │       (LaunchProcess OK)      [ Restarting ]             │
     │   ┌──────────────────────────────────┤                   │
     │   │                                  │ (Stop/Launch fail)│
     │   ▼                                  ▼                   │
     │ [ Running ]                     [ Failed ]               │
     │                                      ▲                   │
     │                                      │                   │
     │                                (Crash / Exit)            │
     │                                      │                   │
     └──────────────────────────────────────┴───────────────────┘
```

#### Detailed State Transition Invariants:
1. **`Stopped` -> `Starting`**: Set immediately prior to `LaunchProcess` in `StartWithJsonCore`.
2. **`Starting` -> `Running`**: Set upon return from `_runner.Start` in `LaunchProcess`, followed by `Started?.Invoke(pid)`.
3. **`Starting` -> `Failed`**: Triggered if `_runner.Start` throws or returns a null handle; TUN ownership is released.
4. **`Running` -> `Restarting`**: Set in `RestartCore` before calling `StopInternal(releaseLock: false)`. Preserved across the Windows 750ms settle delay.
5. **`Restarting` -> `Running`**: Set upon successful respawn in `LaunchProcess` during `RestartCore`.
6. **`Running` -> `Stopped`**: Set in `StopInternal` when handle kill and exit inspection confirm exit (`winStopped == true` / `capabilityStopped == true` / `unixStopped == true`).
7. **`Running` -> `Failed`**:
   - Set in `StopInternal` if process exit state cannot be confirmed (`_exactStopUnconfirmed = true`).
   - Set in `OnProcessExited` when an unexpected process exit occurs (not suppressed by `_restartInProgress` or `_stopInProgress`).

### 3.3. Exit Classification & False-Crash Suppression Pipeline

```
sing-box OS Process Exits
  │
  ▼
IProcessHandle.Exited Event
  │
  ▼
SingBoxManager.OnProcessExited(eventExitCode)
  │
  ├─► Resolve exit code (eventExitCode ?? WaitForExitAsync().Result)
  │
  ├─► Check Suppression Predicate:
  │     (_restartInProgress || _stopInProgress)
  │     AND exitCode in (-1 [Win Terminate], 137 [SIGKILL], 143 [SIGTERM])
  │     │
  │     ├── TRUE (Intentional Teardown Race Winner):
  │     │     ├── Log INF: "Expected exit during intentional {restart|stop}..."
  │     │     ├── LogSingBoxCrashTail() (diagnostic only)
  │     │     ├── DetectTunOrphanCrashSignature() (diagnostic only)
  │     │     └── RETURN (Suppress Crashed event, skip adapter removal)
  │     │
  │     └── FALSE (Genuine Crash or Unhandled Termination):
  │           ├── Log ERR / WARN with exit code
  │           ├── LogSingBoxCrashTail() (reads last 50 lines of singbox.log)
  │           ├── DetectTunOrphanCrashSignature() (sets LastCrashWasTunOrphan / LinuxTunPermission)
  │           ├── State = SingBoxState.Failed
  │           ├── Crashed?.Invoke(this, EventArgs.Empty)
  │           └── Windows: QueueTunAdapterRemoval("OnProcessExited.async")
```

## 4. CONCURRENCY, LOCKS & LIFECYCLE

### 4.1. Lock & Synchronization Primitive Hierarchy

| Primitive | Mechanism | Scope | Protected Invariants / Operations |
|---|---|---|---|
| `_lifecycleGate` | `object` (`Monitor`) | Per-instance | Synchronizes `StartWithJson`, `Stop`, `Restart`, `ReloadConfigJson`, `TryReloadConfigJson`, `KillWedgedForRecovery`. Prevents concurrent lifecycle state mutation. |
| `_stopState` | `int` (`Interlocked.CompareExchange`) | Per-instance | Atomic 0 -> 1 CAS guard at entry of `StopInternal`. Prevents concurrent execution of the kill, process handle clearing, and state manipulation body by competing threads (e.g. UI Disconnect vs HealthMonitor backoff vs AppDomain exit). Resets to 0 in `finally`. |
| `_disposed` | `int` (`Interlocked.CompareExchange`) | Per-instance | Atomic 0 -> 1 CAS guard for `Dispose()`. Read via `Volatile.Read` across threads. Note: Edge-case revival resets to 0 via `Volatile.Write` if stop is unconfirmed. |
| `s_tunRemovalGate` | `object` (`Monitor`) | Static (Class-wide) | Protects access and mutation of `s_pendingTunRemoval` task chain, ensuring ordered Windows PnP removal across sequential and recreating manager instances. |
| `_capturedStderrLock` | `object` (`Monitor`) | Per-instance | Protects the 50-element `_capturedStderr` ring buffer and `_capturedStderrCount` during writes from `ErrorLine` and reads during `DetectTunOrphanCrashSignature`. |
| `TunOwnershipLock` | Named OS Mutex / Semaphore | OS-wide (`Global\VPNRouter-SingBox-Owner`) | Cross-process exclusivity. Guarantees only one VPNRouter process (Desktop UI, Service, or CLI) controls the TUN interface at any given time. |

---

### 4.2. Volatile Memory & Thread Visibility Flags

- `_restartInProgress` (`private volatile bool`): Set `true` at entry to `RestartCore()`, cleared in its `finally` block. Crosses threads to `OnProcessExited` (which runs on a ThreadPool worker) to suppress false crash notifications when sing-box is killed during restart.
- `_stopInProgress` (`private volatile bool`): Set `true` at entry to `StopInternal()`, cleared in its `finally` block. Extends suppression coverage to standard stops (such as server-switch reconnects) where `RestartCore` is not invoked.

---

### 4.3. Sync-over-Async Usage & Deadlock Surface

The codebase intentionally uses sync-over-async (`.GetAwaiter().GetResult()`) because `SingBoxManager` exposes an entirely synchronous API contract while integrating with async subsystems:
1. `TryHotReload` (`SingBoxManager.HotReload.cs:84`):
   - Calls `_http.SendAsync(...).GetAwaiter().GetResult()`.
   - *Mitigation*: Uses an explicit `CancellationTokenSource(TimeSpan.FromSeconds(3))` and sets `HttpRequest.Timeout = TimeSpan.FromSeconds(3)` to bound execution.
2. `IsClashApiAlive` (`SingBoxManager.HotReload.cs:124`):
   - Calls `_http.SendAsync(...).GetAwaiter().GetResult()`.
   - *Mitigation*: Uses an explicit `CancellationTokenSource(TimeSpan.FromSeconds(3))`.
3. `WaitForQueuedTunAdapterRemoval` (`SingBoxManager.Lifecycle.cs:568, 581`):
   - Calls `pending.GetAwaiter().GetResult()` and `TunAdapterDiagnostics.WaitForExactPnpRemovalSettledAsync(...).GetAwaiter().GetResult()`.
   - *Mitigation*: Internal routines use bounded timeouts and polling intervals.
4. `LaunchProcess` (`SingBoxManager.Lifecycle.cs:892`):
   - Calls `TunAdapterDiagnostics.PreStartCleanupAsync(...).GetAwaiter().GetResult()`.
5. `StopInternal` Linux/Windows Kill Wait (`SingBoxManager.Lifecycle.cs:234, 424`):
   - Calls `winTargetHandle.WaitForExitAsync(killCts.Token).GetAwaiter().GetResult()`.
   - *Mitigation*: Hard 5-second `CancellationTokenSource`.
6. `TrySpawnAndWait` (`SingBoxManager.LinuxStop.cs:248`):
   - Calls `_runner.RunAsync(...).GetAwaiter().GetResult()`.
   - *Mitigation*: Bounded by explicit timeout argument (5s or 30s).
7. `OnProcessExited` (`SingBoxManager.CrashDetect.cs:36`):
   - Calls `h.WaitForExitAsync(CancellationToken.None).GetAwaiter().GetResult()`.
   - *Hazard*: Uses `CancellationToken.None` without an explicit timeout. If `HasExited` is true but exit code retrieval deadlocks in the runtime/OS, the ThreadPool thread hangs indefinitely.

---

### 4.4. Teardown & Lifecycle Guarantees

- **`EnableRaisingEvents = false` Invariant**:
  Before calling `Kill()` on process handles during intentional teardowns, `winTargetHandle.SuppressExitedEvent()` is invoked. This decouples the OS process exit event from triggering `OnProcessExited` on the thread pool.
- **Belt-and-Braces Flag Suppression**:
  Because `SuppressExitedEvent()` has a documented 14–33ms race window where the OS callback is already queued on the ThreadPool dispatcher, `_restartInProgress` and `_stopInProgress` act as secondary guards, preventing `Crashed` events from reaching `HealthMonitor`.
- **AppDomain Leak Prevention**:
  `OnAppDomainProcessExit` is declared as a named instance method instead of an anonymous lambda. In `Dispose()`, it is explicitly unsubscribed (`AppDomain.CurrentDomain.ProcessExit -= OnAppDomainProcessExit`), preventing disposed instances from remaining rooted in GC memory.
- **Failed Stop Lease Retention**:
  If an exact process stop cannot be confirmed, `Dispose()` deliberately retains the `TunOwnershipLock` lease and re-subscribes to `AppDomain.ProcessExit` so that an untracked running sing-box process is not collided with by subsequent instances.

## 5. SECURITY & PRIVILEGE BOUNDARIES

### 5.1. Privilege Elevation & Execution Models

1. **Linux Capability-First Execution (Least Privilege)**:
   - Evaluates `HasNetCapability` via `getcap`. If `cap_net_admin` and `cap_net_bind_service` are effective, spawns sing-box as an unprivileged user process.
   - Bypasses polkit prompts (`pkexec`) and runs with standard user credentials while permitting network interface creation.
2. **Linux Elevation Fallback (`pkexec`)**:
   - If capabilities are absent, resolves `pkexec` via `LinuxRuntimeEnvironment.ResolvePkexec()`.
   - Enforces polkit authentication. Spawns sing-box as root.
3. **macOS Elevation (`sudo`)**:
   - Uses `/usr/bin/sudo` with pre-configured NOPASSWD entries configured during initial connection setup.
4. **Linux Headless / Sandbox Policy Enforcement**:
   - Checks `SingBoxRuntimePolicy.Current`. If policy is active:
     - Disallows implicit elevation via `pkexec` or `sudo`.
     - Direct execution only; refuses launch if privileges or required capabilities are missing.
     - Enforces strict binary authorization checks (`policy.Authorize(...)`).
   - Checks `LinuxRuntimeEnvironment.GetTunPrivilegeBlocker()` to fail fast if running in restricted sandboxes (e.g. Snap/Flatpak without permissions).

---

### 5.2. Unix Process Signaling & PID Reuse Defenses

To prevent signaling an unrelated process that reused an old PID (PID recycling vulnerability):
- `ProcessOwnership.FindOwnedSingBox` reads the durable runtime owner record containing PID, start time ticks (`StartedAtUtcTicks`), and binary path.
- `UnixOwnedProcessSignal.SignalLinux` opens a `pidfd` (`SYS_pidfd_open`), re-reads process identity from `/proc/<pid>`, validates start time and binary path against expected identity, and sends the signal directly through the `pidfd` (`SYS_pidfd_send_signal`).
- If escalating to root via `pkexec` or `sudo`, arguments pass the exact identity tokens (`--vpnrouter-internal-signal-owned-v1 <pid> <ticks> <exePath> <signal>`), and the internal helper validates them before signaling.
- Process-name patterns (e.g. `pkill sing-box`) are strictly avoided.

---

### 5.3. Configuration File Permissions & Clash API Protection

- **File Permissions**:
  `WriteJsonToDisk` invokes `AppPaths.EnsurePrivateUnixDirectory` (sets directory permissions to `0700`) and `AppPaths.WritePrivateText` (writes configuration files with `0600` permissions). This prevents unauthorized local users from reading proxy credentials, server endpoints, or Clash API secrets.
- **Clash REST API Authentication**:
  When `SingBoxSettings.ClashApiSecret` is populated, HTTP requests inject `Authorization: Bearer <secret>`. All Clash API endpoints bind strictly to localhost (`127.0.0.1:{port}`).

### 6.2. Detailed Analysis of Defect Candidates

#### 1. CRITICAL: `IsHealthy()` Broken on Linux when using `pkexec`
- **Location**: `VPNRouter.Core/Services/SingBoxManager.Health.cs:33-40`
```csharp
public bool IsHealthy()
{
    if (OperatingSystem.IsMacOS())
        return State == SingBoxState.Running && IsClashApiAlive();

    if (_handle == null || _handle.HasExited)
        return false;
    ...
```
- **Evidence & Root Cause**:
  In `SingBoxManager.Health.cs:13-25`, the comment explicitly explains that on Linux with `pkexec`, the tracked process wrapper exits immediately:
  > *"Linux pkexec wrapper exited after spawning the root child — `_process.HasExited=true` even though sing-box is alive. In all three cases Clash API still answers if the tunnel is up... Drop the State gate on Unix and trust the HTTP probe."*
  Accordingly, `IsRunning()` checks `if (OperatingSystem.IsMacOS() || OperatingSystem.IsLinux()) return IsClashApiAlive();`.
  However, in `IsHealthy()`, line 35 checks *only* `OperatingSystem.IsMacOS()`. On Linux when `_linuxUsedPkexec == true`, line 38 checks `_handle.HasExited`, which is `true`. `IsHealthy()` immediately returns `false`.
- **Impact**: Any health monitoring check or diagnostic evaluating `IsHealthy()` on Linux distributions without capabilities (AppImage, manual tarball, or non-deb installs) will permanently consider sing-box unhealthy, potentially triggering unnecessary failover loops or degraded UI warnings.

#### 2. HIGH: Resurrecting Disposed Manager State on Unconfirmed Stop
- **Location**: `VPNRouter.Core/Services/SingBoxManager.cs:399-406`
```csharp
if (_ownsTunLock)
{
    _logger.Warning(
        "[SingBoxManager] Dispose preserved TUN ownership because exact stop was not confirmed (state={State})",
        State);
    AppDomain.CurrentDomain.ProcessExit += OnAppDomainProcessExit;
    Volatile.Write(ref _disposed, 0);
}
```
- **Evidence & Root Cause**:
  In `Dispose()`, `Interlocked.CompareExchange(ref _disposed, 1, 0)` is used to guarantee single execution. However, if `_ownsTunLock` is still true because `_exactStopUnconfirmed == true`, the method re-subscribes to `ProcessExit` and resets `_disposed = 0`.
- **Impact**: Violates .NET disposable invariants. Subsequent calls to `Dispose()` will re-run disposal code. If the instance was disposed inside a `using` block, the object appears alive (`_disposed == 0`), but internal references (like partially torn down state or suppressed event flags) are corrupted.

#### 3. MEDIUM: Incomplete JSON Escaping in `TryHotReload`
- **Location**: `VPNRouter.Core/Services/SingBoxManager.HotReload.cs:75`
```csharp
var body = $"{{\"path\":\"{_currentConfigPath.Replace("\\", "\\\\")}\"}}";
```
- **Evidence & Root Cause**:
  Constructs raw JSON via string interpolation. While backslashes are doubled, double quotes (`"`) or unusual control characters in file paths are unescaped.
- **Impact**: If a user runs VPNRouter from a profile directory containing special characters or quotes, the Clash API returns HTTP 400 Bad Request, hot-reload fails, and sing-box is unnecessarily terminated and restarted.

### 7.2. Critical Test Coverage Gaps

1. **Linux `pkexec` Mode `IsHealthy()` Evaluation**:
   - There are no unit or integration tests verifying `IsHealthy()` when `_linuxUsedPkexec == true` and `_handle.HasExited == true`. This explains why the critical defect in `IsHealthy()` went undetected.
2. **`OnProcessExited` ExitCode Retrieval Deadlock**:
   - No tests simulate `_handle.WaitForExitAsync(CancellationToken.None)` taking an extended period or stalling when handling exit events.
3. **Unconfirmed Stop Disposal Re-entry**:
   - No test exercises calling `Dispose()` when `_exactStopUnconfirmed` is forced to `true`, verifying behavior when `_disposed` is reset to 0.
4. **Special Character Paths in `TryHotReload`**:
   - No tests test hot-reloading configs with non-standard file paths (containing quotes, spaces, or Unicode symbols).
5. **Linux `getcap` Output Variations**:
   - No tests cover localized or non-standard `getcap` output formats or failure modes (e.g. exit code 1, permission denied reading xattrs).
6. **Cancellation Token Propagation in Hot Reload**:
   - The reload methods `ReloadConfigJson` and `TryReloadConfigJson` take no `CancellationToken` parameter from caller APIs, preventing external callers from aborting stalled reload operations.
