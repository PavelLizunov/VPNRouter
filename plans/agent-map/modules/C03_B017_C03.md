> **TL;DR:** Module C03 (`AppJsonContext.cs`, `YamlStaticContext.cs`, and `DateTimeOffsetYamlConverter.cs`) implements VPNRouter's compile-time static serialization layer for System.Text.Json and YamlDotNet, eliminating dynamic code generation (IL3050) for NativeAOT and Android compatibility. The audit identified key architectural caveats: `YamlStaticContext` silently emits empty mappings (`{}`) if any newly added model is not explicitly registered (as occurred in the historical AWG key-loss defect); `DateTimeOffsetYamlConverter` throws unhandled `FormatException` on malformed date strings and `YamlException` on non-scalar nodes; and `AppJsonContext` enforces a strict 32-level recursion limit (`MaxDepth = 32`) as a JSON-DoS defense.

# Exhaustive Code Inventory & Audit: Core Serialization (Module C03 / Batch B017_C03)

## 1. SUMMARY & PURPOSE

Module `C03` encapsulates the core compile-time serialization infrastructure for `VPNRouter.Core`. It comprises three specialized components:
- **`VPNRouter.Core/Json/AppJsonContext.cs` (162 LOC)**: Roslyn source-generated `System.Text.Json.Serialization.JsonSerializerContext` registering 25 mission-critical Data Transfer Objects (DTOs) and collections for reflection-free JSON serialization.
- **`VPNRouter.Core/Yaml/YamlStaticContext.cs` (108 LOC)**: Roslyn source-generated `YamlDotNet.Serialization.StaticContext` providing static object factories and type inspectors for 20 configuration DTOs.
- **`VPNRouter.Core/Yaml/DateTimeOffsetYamlConverter.cs` (84 LOC)**: Custom `YamlDotNet.Serialization.IYamlTypeConverter` bridging a defect in the static YAML analyzer's scalar coercion table for `DateTimeOffset` and `DateTimeOffset?`.

### Component Roles & Responsibilities

1. **`AppJsonContext.cs`**:
   - **NativeAOT & Trimming Readiness**: Eliminates `RequiresDynamicCode` (IL3050) and reflection trimming warnings across core JSON paths. Under .NET NativeAOT (specifically targeted for Android startup acceleration and standalone CLI deployment), runtime reflection on stripped metadata fails. `AppJsonContext` pre-generates `JsonTypeInfo<T>` resolvers at compile time.
   - **Unified Context Options**: Implements a defense-in-depth posture via `[JsonSourceGenerationOptions]`:
     - `MaxDepth = 32`: Mitigates JSON-DoS attacks (e.g. deeply nested recursion payloads from untrusted subscription feeds, QR share documents, or compromised update feeds).
     - `DefaultIgnoreCondition = WhenWritingNull`: Prevents polluting sing-box configuration files and cache documents with null properties.
     - `PropertyNameCaseInsensitive = true`: Preserves wire compatibility with hand-edited configs and legacy Newtonsoft outputs.
     - `WriteIndented = true`: Standardizes human-readable JSON formatting across disk caches, diagnostic exports, and sing-box runtime configs.
     - `NumberHandling = JsonNumberHandling.AllowReadingFromString`: Tolerates string-quoted numbers returned by Clash REST endpoints (e.g. `downloadTotal: "12345"`).
   - **Dual Serialization Mechanics**: Operates both as a direct typed resolver (`JsonSerializer.Serialize(cfg, AppJsonContext.Default.SingBoxConfig)`) and as the primary stage in a combined resolver pattern (`JsonTypeInfoResolver.Combine(AppJsonContext.Default, new DefaultJsonTypeInfoResolver())`).

2. **`YamlStaticContext.cs`**:
   - **Static YAML Inspection & Construction**: Extends `Vecc.YamlDotNet.Analyzers.StaticGenerator` to provide static reflection tables for `StaticDeserializerBuilder` and `StaticSerializerBuilder` in `SettingsLoader.cs`.
   - **Persistent Config Surface Documentation**: Explicitly catalogues every leaf DTO participating in the `config.yaml` schema (`AppSettings`, `AppConfig`, `VlessConfig`, `TunSettings`, `AwgConfig`, etc.).
   - **Transitive Generic Resolution**: Avoids an upstream analyzer crash (`IndexOutOfRangeException`) on explicit generic definitions (`Dictionary<string, List<string>>`) by registering leaf DTOs and allowing the analyzer's syntax receiver to discover collections transitively.

3. **`DateTimeOffsetYamlConverter.cs`**:
   - **Analyzer Coercion Shim**: `Vecc.YamlDotNet.Analyzers.StaticGenerator` 15.1.2/18.1.0 omits `DateTimeOffset` from its scalar coercion table. Without this converter, the static serializer emits `{}` (empty mapping) and the deserializer throws `ArgumentOutOfRangeException: Unknown type: System.DateTimeOffset`.
   - **Lossless ISO 8601 Persistence**: Enforces byte-for-byte lossless round-trip serialization using the ISO 8601 `"O"` (round-trip date/time) format specifier with `CultureInfo.InvariantCulture` and `DateTimeStyles.RoundtripKind`.
   - **Nullable & Default Handling**: Gracefully handles null and empty YAML scalars by mapping them to `null` for `DateTimeOffset?` and `default(DateTimeOffset)` (`DateTimeOffset.MinValue`) for non-nullable values.

## 4. CONCURRENCY, LOCKS & LIFECYCLE

### 4.1 Concurrency & Thread-Safety Guarantees

1. **`AppJsonContext`**:
   - The static singleton instance `AppJsonContext.Default` is initialized once by the CLR during static class initialization and is completely immutable.
   - `JsonTypeInfo<T>` instances emitted by the Roslyn source generator are stateless, thread-safe, and designed for high-concurrency access across thread pool workers.
   - Concurrent serialization/deserialization calls in `VpnEngine`, `HealthMonitor`, and `ClashSingBoxApi` execute lock-free.
2. **`YamlStaticContext`**:
   - Holds static lookup tables (`IObjectFactory`, `ITypeInspector`). The static context class itself is instantiated per serialization/deserialization run in `SettingsLoader`:
     ```csharp
     var deserializer = new StaticDeserializerBuilder(new YamlStaticContext())...
     var serializer = new StaticSerializerBuilder(new YamlStaticContext())...
     ```
   - Because a fresh `YamlStaticContext` instance is passed to each builder, there is zero cross-thread state pollution. However, the static type tables generated by `Vecc` are read-only and thread-safe.
3. **`DateTimeOffsetYamlConverter`**:
   - Completely stateless; contains no instance or static mutable fields.
   - Uses `CultureInfo.InvariantCulture`, which is guaranteed thread-safe by the .NET runtime.
   - Multiple threads running `SettingsLoader.Parse` or `SettingsLoader.Save` operate independently without lock contention.

### 4.2 Async & Cancellation Semantics

- **JSON Subsystem**:
  - Fully integrates with `System.Text.Json` asynchronous streaming APIs.
  - Used in `ClashSingBoxApi.cs` with explicit cancellation tokens:
    ```csharp
    await JsonSerializer.DeserializeAsync(stream, Json.AppJsonContext.Default.VersionDto, deadlineCts.Token).ConfigureAwait(false);
    ```
  - Honors `CancellationToken` teardown guarantees without thread-blocking.
- **YAML Subsystem**:
  - `YamlDotNet` does not support asynchronous parsing or serialization. All operations (`deserializer.Deserialize<AppSettings>(yaml)` and `serializer.Serialize(settings)`) are strictly synchronous and CPU-bound.
  - In `SettingsLoader.cs`, disk I/O for `config.yaml` is wrapped in synchronous `File.ReadAllText` and `writer.Write` calls. No cancellation tokens are accepted during configuration persistence.

## 5. SECURITY & PRIVILEGE BOUNDARIES

### 5.1 Defense-in-Depth & Denial of Service Protection

1. **JSON Recursion Limit (`MaxDepth = 32`)**:
   - Declared on `AppJsonContext` (line 126).
   - Standard `System.Text.Json` allows a depth of 64; `Newtonsoft.Json` was unbounded.
   - VPNRouter restricts recursion to 32 levels. The deepest production model (`ConfigShareDocument` wrapping `SingBoxConfig`) reaches ~6 levels.
   - A malicious actor providing deeply nested JSON (e.g. via an imported subscription URL or QR share code) is aborted with a `JsonException` before memory exhaustion or a stack overflow occurs.

2. **Permissive Numeric String Ingestion**:
   - `NumberHandling = JsonNumberHandling.AllowReadingFromString` is enabled globally on `AppJsonContext`.
   - **Boundary**: sing-box Clash REST API emits numeric metrics (e.g., `downloadTotal`, `uploadTotal`, `port`) as JSON strings in certain edge cases. Allowing reading from strings hardens the telemetry reader against crash loops.
   - **Risk**: Extends to all registered DTOs. A numeric field in `AppSettings` or `CustomRule` can accept string-formatted numbers without schema validation errors.

3. **Lossless Temporal Precision (`DateTimeOffsetYamlConverter`)**:
   - Enforces `CultureInfo.InvariantCulture` and format `"O"` (ISO 8601).
   - Prevents locale-dependent parsing vulnerabilities where non-Western calendars (e.g., Thai Buddhist calendar `th-TH`, Saudi Um Al-Qura `ar-SA`) alter the year by 543 years or substitute digits, corrupting cache expiration stamps and subscription refresh schedules.

4. **Credential Exposure Risk**:
   - High-privilege credentials pass through both serialization pipelines:
     - Reality Private/Public Keys, Short IDs (`VlessRealityConfig`).
     - AmneziaWG Private Keys, Preshared Keys (`AwgConfig`).
     - Proxy server UUIDs (`VlessServerEntry.Uuid`).
     - Telegram Proxy Secrets (`AppConfig.TgProxySecret`).
   - `AppJsonContext` sets `DefaultIgnoreCondition = WhenWritingNull`. Null properties are omitted, preventing secret key scaffolding from appearing in empty exports.
   - `SettingsLoader.Save` persists these secrets to disk using `AppPaths.CreatePrivateFile(tmp)` (`0600` on Unix, ACL restricted to System/Admin/User on Windows), mitigating local privilege escalation (LPE).

## 6. SUSPICIOUS PATTERNS / DEFECT CANDIDATES

### 6.1 Critical Architectural Defect: Silent Data Loss on Unregistered YAML DTOs

- **Vulnerability / Defect Description**:
  The `Vecc.YamlDotNet.Analyzers.StaticGenerator` does NOT throw a compilation error or runtime exception when an unregistered nested DTO class is encountered during serialization. Instead, it emits an empty mapping (`{}`).
- **Historical Evidence**:
  In version `v2.45.0-r1/r2`, `AwgConfig` was added to `VlessServerEntry` but omitted from `YamlStaticContext.cs`. When `SettingsLoader.Save()` was called, the serializer emitted `awg: {}`. On restart, `Vless.Servers` failed validation and was wiped completely.
- **Risk Severity**: **HIGH (Latent Regression Hazard)**.
- **Location**: `VPNRouter.Core/Yaml/YamlStaticContext.cs`.
- **Recommendation**: Maintain strict automated reflection-based unit tests that compare all types in `VPNRouter.Core.Models` against the `[YamlSerializable]` attributes on `YamlStaticContext`.

### 6.2 Analyzer Crash on Generic Type Registrations

- **Defect Description**:
  Attempting to register generic collection types directly (e.g., `[YamlSerializable(typeof(Dictionary<string, List<string>>))]`) triggers an unhandled `IndexOutOfRangeException` in `Vecc.YamlDotNet.Analyzers.StaticGenerator 18.1.0` during build time.
- **Current Mitigation**:
  Lines 31–39 of `YamlStaticContext.cs` document the workaround: only leaf DTOs are registered, relying on transitive discovery by `ClassSyntaxReceiver.CheckForSupportedGeneric`.
- **Risk Severity**: **MEDIUM (Build-time fragility)**.
- **Impact**: If a collection type is detached or referenced only through an `object` property, transitive discovery will fail and the collection will not be serialized.

### 6.3 Unhandled `FormatException` in `DateTimeOffsetYamlConverter.ReadYaml`

- **Code Location**: `VPNRouter.Core/Yaml/DateTimeOffsetYamlConverter.cs`, lines 68–71:
  ```csharp
  return DateTimeOffset.Parse(
      scalar.Value,
      CultureInfo.InvariantCulture,
      DateTimeStyles.RoundtripKind);
  ```
- **Defect Description**:
  If a user manually edits `config.yaml` and enters an invalid date string (e.g. `last_refreshed_at: "not-a-date"`), `DateTimeOffset.Parse` throws `FormatException`.
- **Failure Cascade**:
  While `SettingsLoader.Parse` catches general YAML exceptions and wraps them in `InvalidDataException`, a malformed date does not provide a property-level diagnostic and causes full configuration reset or fallback to defaults.
- **Recommendation**:
  Replace `DateTimeOffset.Parse` with `DateTimeOffset.TryParse`. On failure, return `null` (for nullable) or `DateTimeOffset.MinValue` with a logged diagnostic warning.

### 6.4 `YamlException` on Non-Scalar YAML Nodes

- **Code Location**: `VPNRouter.Core/Yaml/DateTimeOffsetYamlConverter.cs`, line 57:
  ```csharp
  var scalar = parser.Consume<Scalar>();
  ```
- **Defect Description**:
  `parser.Consume<Scalar>()` strictly assumes the next event in the parser stream is a scalar. If the YAML document contains a sequence or mapping where a date is expected (e.g. `last_refreshed_at: [2026, 05, 18]` or `last_refreshed_at: { day: 18 }`), YamlDotNet throws `YamlException: Expected 'Scalar', got 'MappingStart'`.
- **Recommendation**:
  Check `parser.Current is Scalar` before consuming; if another node type is present, skip the node recursively and return default/null.

### 6.5 Disk Space Inflation on Bulk Caches via Global `WriteIndented = true`

- **Code Location**: `VPNRouter.Core/Json/AppJsonContext.cs`, line 125.
- **Defect Description**:
  Setting `WriteIndented = true` on `AppJsonContext` applies globally to all 25 registered types.
- **Impact**:
  For `FreeConfigCache.CacheFile` (which aggregates up to 25,000 public VLESS configurations), indented JSON expands the file size from ~30 MB to ~32 MB on disk (+5–10% expansion). This increases disk write latency and GC allocations during periodic 6-hour cron updates.

### 6.6 CS9023 Visibility Leaking on `YamlStaticContext`

- **Code Location**: `VPNRouter.Core/Yaml/YamlStaticContext.cs`, line 106.
- **Defect Description**:
  `YamlStaticContext` is declared `public partial class` despite being an internal implementation detail of `VPNRouter.Core.Yaml`.
- **Reason**:
  The `Vecc.YamlDotNet.Analyzers.StaticGenerator` hardcodes `public partial class {ContextName}` in its emitted code. Declaring the user partial class as `internal` results in compilation error CS9023.
- **Impact**:
  Exposes `YamlStaticContext` to external assemblies referencing `VPNRouter.Core`, though external callers are expected to consume `ISettingsStore` / `SettingsLoader`.

   - `JsonNumberHandling.AllowReadingFromString` is not explicitly tested across all registered numeric types to verify whether malformed string numbers (e.g. `"123a"`) throw or silently coerce.
