## Главные выводы аудита Пакета 21A

1. **Критическая ценность сетевой устойчивости**:
   - `VpnDnsBootstrapTests` решает классическую проблему «курицы и яйца» для DoH: чтобы подключиться к DoH-резолверу `https://1.1.1.1/dns-query`, нужно сначала разрешить имя его хоста через локальный DNS без туннеля, не допуская циклического зависания.
   - `UdpDegradationDetectorTests` обеспечивает автоматический мягкий переход на резервный транспорт при деградации UDP-трафика провайдером без обрыва всей сессии.

2. **Надёжность отката обновлений (`UpdateBackupTests`)**:
   Все 13 поведенческих тестов гарантируют сохранность установленной программы: если процесс обновления прерван или поврежден, приложение автоматически откатывается к рабочей резервной копии без участия пользователя.
