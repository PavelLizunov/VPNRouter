# Roblox Error 277 over VPN-from-Russia — root-cause analysis + corrected fix

Source: 10-agent research workflow (wf_58b6881e-be6) over diag
`VPNRouter-diagnostics-20260627-203104.zip` (tester on 2.44.4-r4, full-tunnel,
subscribe, active = "Germany VLESS"), the actual ConfigGenerator code, RU-censorship
sources, and two adversarial verifications. Confidence: HIGH on root cause + the
KEEP/REVERT verdicts; MEDIUM that the UDP-native remedy works from RU (needs a live RU test).

## What Error 277 actually is
A **realtime-UDP quality failure AFTER join** — RakNet receives no game packets for
~10-15 s and times out. NOT a web/login error. So "route the game direct" is the wrong
axis: login already needs the VPN (RU blocks roblox.com); the in-game UDP is what breaks.

## Ranked root causes
1. **HIGH — game UDP rides VLESS-over-TCP.** On a plain VLESS+Reality+Vision server
   (Germany VLESS) `ConfigGenerator.BuildOutbounds` sets `hasUdpProxy=false`, so the
   single `proxy` (VLESS = TCP transport) carries UDP as xudp-over-TCP → TCP-over-TCP
   head-of-line blocking → one lost outer segment stalls the whole RakNet stream → 277.
   A healthy `proxy-udp(hysteria2)` only appears when the active server is NAIVE with a
   co-located HY2 sibling (the Latvia path) — not on a plain VLESS server.
2. **HIGH — Roblox DNS resolves through the congested proxy detour.** `vpn-dns` detour=
   proxy in full-tunnel → 1023 DNS exchanges >=10 s (worst ~60 s), 622/2528 Roblox
   lookups >=2 s → joins stall → 277/failed join. `local-dns`(dns-direct, real NIC) exists
   but is unused in full-tunnel.
3. **MEDIUM — sing-box full restarts tear down live sessions.** 5 "Forced full restart
   (structural change)" on subscription re-aggregation during the capture; each drops the
   live RakNet UDP NAT mapping → instant 277 mid-match.

## Why "route Roblox direct" cannot work from RU (both adversarial verifies = false)
RU TSPU/DPI freezes foreign-datacenter IPs for **both TCP and UDP** (net4people/bbs #490,
upd5: freeze after ~25 packets / ~16 KB). Direct game UDP to Roblox edges is exactly what
RU kills — diag shows 231 i/o-timeouts to 128.116.5.3:443 ALL on `outbound/direct`, while
the same IP via `proxy(VLESS)` answers in 354 ms. Direct TCP also breaks login. So a
per-process TCP-proxy/UDP-direct split is non-viable, and Codex's whole-process-direct rule
is strictly worse (kills login too).

## Verdict on Codex's uncommitted changes
- **`route_games_direct` (default true) → REVERT.** The rule (ConfigGenerator.cs:~1724)
  routes the whole `RobloxPlayerBeta.exe`/`Launcher` process to `direct` with no
  `Network=udp` qualifier → sends TCP login direct → RU-blocked. It both breaks login and
  pushes game UDP onto the RU-frozen direct path. Most directly responsible for making 277
  worse. Default to false; preferably remove the whole-process rule.
- **MTU 1500->1280 migration (schema v7) → KEEP as HARDENING, not the fix.** Small RakNet
  datagrams (<1200 B) never fragment at 9000/1500/1280; zero fragmentation evidence in logs.
  Directionally fine (also fixes the live `mtu: 9000`), but does not address the 277 cause.
- **HealthMonitor 2-consecutive-fail debounce → KEEP.** Sound — stops a single transient
  UDP gap from flapping the tunnel. SEPARATELY: gate "Forced full restart (structural
  change)" to hot-reload when only route rules changed, so a subscription refresh mid-game
  doesn't tear down the live UDP session.

## Correct architecture
Keep ALL Roblox traffic IN the tunnel; make game UDP ride a **UDP-native** transport
(Hysteria2 QUIC / TUIC native), not VLESS-over-TCP. QUIC does per-stream loss recovery →
no HoL → no 277. Load-bearing requirement: the Roblox-exit server must offer a UDP-native
path. Simplest: connect to Roblox via a **Hysteria2 server** (carries TCP+UDP natively from
one exit — also removes any TCP/UDP exit-IP mismatch). Plus:
- `packet_encoding`: leave at sing-box default xudp (FullCone NAT for RakNet's multiple
  endpoints); never set it to empty.
- `udp_timeout`: keep TUN default 5m (don't shorten — would drop the in-session NAT map).
- TUN MTU = 1280 (already the code default + migrations).
- DNS: don't let a stalled proxy-detour DoH hang Roblox joins — bounded timeout + fallback,
  or resolve `*.roblox.com` off the congested detour. Web/login stays on proxy.
- No mux, no TCP-Brutal on the game path.
