# v2.32.0 — Android Free Configs port

## Триггер

Android-порт упирается в самую заметную feature-gap по сравнению с desktop'ом
— у пользователя без своей подписки нет одно-кнопочного способа найти
работающий бесплатный VLESS-сервер. На desktop'е это решено через
`FreeConfigsPage` (Поиск + Сохранённые табы). На Android фичи нет.

Все Core-сервисы (`FreeConfigPoolFetcher`, `FreeConfigCache`,
`FreeConfigTester`, `FreeConfigSources`) уже мульти-таргетят (нет
Windows-only API), и компилируются в Android-сборку как Source link
(см. `VPNRouter.Android.csproj:77-80`). Не хватает только UI-слоя.

## Симптом

User open the Android app, не имеет своего сервера, и — в отличие от
desktop'а — нет кнопки «найди мне сервер». Должен идти искать в
Telegram-каналах, копировать vless://… вручную.

## Root cause

`VPNRouter.App/Views/Pages/FreeConfigsPage.axaml` + `~/ViewModels/FreeConfigs/*` —
Avalonia desktop UI, не портированы на Android view layer
(`VPNRouter.Android/AndroidApp.axaml.cs` — single-screen фабрика без
секций под Free Configs).

### Не портируем (constraint differences)

| Element | Reason |
|---|---|
| Deep Verify (FreeConfigDeepVerifier) | Desktop spawns extra sing-box.exe per probe. На Android sing-box живёт в-process через libbox, экземпляр единственный. Status=Ok (TCP+TLS) — наш success bar. |
| Bandwidth column | Без Deep Verify нет измерения throughput. Колонку убираем — экономит ~80px на phone screen. |
| Cross-batch overlap pipeline + adaptive deep cap | Без Deep Verify не нужно. Простой батч TCP+TLS. |
| GC.Collect + LOH compact + Skia.PurgeAllCaches | Не управляем GC на Android вручную. |
| User-source management (Add/Remove URL) | Power-user фича, идёт в Phase 8.x при нужде. |
| Recheck-bulk + per-row Recheck | Without Deep Verify эти команды только TCP-ping заново гоняют. Saved-tab показывает то что нашли при последнем поиске, без in-place refresh. Phase 8.x при необходимости. |

## Fix strategy

1. **`AndroidFreeConfigsOrchestrator.cs`** (new) — лёгкий аналог
   `FreeConfigsPageViewModel`, без Avalonia.Threading.Dispatcher (мы уже
   на UI thread в Android view). Методы:
   - `EnsureCacheLoaded()` — `FreeConfigCache.Load()` → `_savedConfigs`
   - `RefreshAsync(target, maxPingMs, excludeRu, ct)` — pool fetch →
     filter (excludeRu, dedupe by IP) → batch TCP+TLS test →
     emit per-tick `OnFound(item)` events до достижения target
   - `Save(entry)` — `UpsertSaved` + write cache
   - `Cancel()` — cts cancel
   - Events: `OnStatus(string)`, `OnProgress(done,total)`, `OnFound(item)`,
     `OnFinished(verifiedCount)`, `OnFailed(error)`
2. **`AndroidApp.axaml.cs` — BuildFreeConfigsOverlay`** — новый Border
   overlay, lives рядом с `_logOverlay` + `_appPickerOverlay` в `outerGrid`.
   Layout совпадает с desktop master-detail (sub-tab strip + body + bottom).
3. **Kebab menu entry** — добавляем секцию «Бесплатные конфиги» в
   `AndroidApp` kebab popup (mirror desktop's main tab nav). Tap → open
   overlay.
4. **Use server flow** — на tap Connect CTA в overlay'е:
   ```
   var entry = selected.Entry;
   AndroidStorage.SetVlessUri(entry.RawUri);
   AndroidStorage.SetSubscriptionUrl(null);
   AndroidStorage.SetServers(null);
   AndroidStorage.SetSelectedServerName(null);
   // close overlay
   MainActivity.Instance?.RequestConnect();
   ```
5. **Localization** — добавить RU/EN строки в `Localization.cs` под
   секцию «Free configs» (label, sub-tab headers, actions, status
   templates, error messages).
