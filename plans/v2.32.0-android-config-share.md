# v2.32.0 — Android config share (export / import / QR)

**Status**: Draft, 2026-05-07. Implementation in progress on branch
`claude/cranky-hermann-2ec5c2`. Targets v2.32.0-rN ship.

## Триггер

User-feature ask: на Android'е хочется экспортировать всю текущую
настройку — подписки, custom sing-box JSON, ручной VLESS URI, опционально
настройки + per-app filter — одним файлом. Импортировать на другом
устройстве (или восстановить после Clear data). Плюс QR-код для быстрой
передачи одного VLESS URI: показать на одном устройстве, отсканировать
на другом.

Desktop export/import существует только для `CustomRule` lists
(`VPNRouter.Core/Services/CustomRulesImportExport.cs`). Полного config
export/import desktop пока не имеет — это Android-led feature; десктоп
получит ту же ручку отдельным P2 follow-up'ом.

## Симптом

- Поменял подписку → потерял список серверов до следующего refresh.
- Reinstall'нул APK → SharedPreferences сброшен → всё с нуля.
- Хочется поделиться рабочим VLESS URI'ем с другом — копи-паста через
  мессенджер некрасиво и легко обрезается.

## Решение

### Schema — `ConfigShareDocument` (VPNRouter.Core)

Один JSON-файл, version-tagged. Опциональные поля отсутствуют когда не
выбраны при export (включить настройки / включить per-app filter — отдельные
тогглы, по умолчанию OFF потому что device-specific).

```jsonc
{
  "schema":      "vpnrouter-config-share",
  "version":     1,
  "exported_at": "2026-05-07T18:30:00Z",
  "exported_from": {
    "platform":     "android",      // "android" | "windows" | "macos" | "linux"
    "app_version":  "2.32.0-r2",
    "device_label": "KYOCERA A101BM"  // hostname / Build.MODEL — best-effort
  },

  "config_mode": "subscribe",       // "subscribe" | "manual" | "custom"

  // ── Always-included payload (no opt-in checkbox) ──────────────────
  "subscriptions": [                // SubscriptionEntry[] verbatim
    {
      "id":                "abc...",
      "name":              "Default",
      "url":               "https://example.com/vless.txt",
      "enabled":           true,
      "last_refreshed_at": "2026-05-07T15:00:00Z",
      "last_server_count": 12,
      "servers":           [ /* VlessServerEntry[] cached */ ]
    }
  ],
  "manual_vless_uri":      "vless://...#friendly-name",  // single-URI mode (when ConfigMode=="manual")
  "custom_config":         {        // when ConfigMode=="custom"
    "name":          "my-tuic-server",
    "sing_box_json": "{...}"          // raw JSON pasted by user; we don't re-format
  },

  // ── Opt-in: settings (theme/lang/routing/dns/etc) ─────────────────
  "settings": {                     // null when not opted-in
    "theme":          "light",
    "language":       "ru",
    "routing_mode":   "split",
    "bypass_ru":      true,
    "block_on_vpn_fail": false,
    "dns_strategy":   "ipv4_only",
    "update_channel": "stable",
    "autostart_vpn":  false,
    "autostart_zapret": false,
    "autostart_tgproxy": false
  },

  // ── Opt-in: per-app filter ────────────────────────────────────────
  "per_app_filter": {               // null when not opted-in (device-specific!)
    "mode":     "include",
    "packages": [ "com.discord", "com.spotify.music" ]
  }
}
```

**Naming convention**: `vpnrouter-config-YYYYMMDD-HHmm.json`. Extension
`.json` (NOT custom `.vpnrouter`) — лучше совместимость с Android Storage
Access Framework picker filter `application/json`.

### QR encoding strategy

| Сценарий | Что в QR | Размер |
|---|---|---|
| Поделиться **одним VLESS URI** | сам URI (`vless://...`) | 100-300 chars → QR M-level |
| Поделиться **полным конфигом** | НЕ через QR (>2KB обычно). Ship через JSON-файл |

QR — только для single VLESS URI flow. Это match'ит десктопный паттерн
`SmpUriShareToggle` где user копирует URI и шлёт мессенджером — мы
заменяем "копировать → вставить" на "посмотрел → отсканировал".

QR encoder — vendor pure-C# implementation (Project Nayuki BSD-licensed,
~600 LOC single file). Никаких NuGet'ов, никаких Android-specific binding'ов.
Generated matrix `bool[,]` рендерится в Avalonia bitmap через простой
pixel loop.

QR scanner — для v1 не делаем full CameraX integration. Вместо этого:
1. Показываем поле "Вставить URI из буфера" в том же оверлее QR.
2. Подсказка "Откройте Камера приложения, наведите на QR — система
   сама распознает URL и предложит скопировать. Затем вставьте сюда".

Большинство Android'ов >= 12 (наша поддерживаемая база — API 23+, на
практике все тестовые девайсы 12+) умеют распознавать QR в системной
Камере без нашего CameraX. Live-camera scan — Phase 2 follow-up если
нужен будет, но обычно clipboard flow достаточен.

**Альтернатива** если live-scan очень важен: вернуться к ZXing.Net
(pure C# decoder) + `Intent.ACTION_GET_CONTENT` для pick-from-gallery,
декодим pixel byte[] → URI string. Но без NuGet ZXing у нас нет, а
vendoring decoder — это ещё ~2K LOC сверху encoder'а.

### Security considerations

- **VLESS URI is effectively a password**. UUID + Reality public key
  даёт полный access к серверу. Если QR показан в публичном месте /
  снят на чужой телефон — компрометация эквивалентна паролю.
  → Перед тем как показать QR / экспортировать — banner
    `"Не делитесь экспортом / QR-кодом в открытых каналах. UUID = пароль."`
- **Subscription URL может содержать токен**. Та же логика — banner.
- **Custom sing-box JSON может содержать TLS cert / key**. Не наша
  типичная угроза но banner коммон.
- **Backup before import** — перед `Apply` снимок текущего состояния
  кладётся в `getFilesDir()/backup/before-import-{ts}.json`. Если новый
  configimport ломает coordin, user может через UI восстановить из
  backup'а (или через `adb pull` для recovery).

### Mirror desktop?

Handbook §1.1 правило: "desktop reference — source of truth". Но десктоп
не имеет полного config-export'а. Поэтому я создаю pattern В Core —
который потом будет использован и на desktop'е (отдельный P2 follow-up).
Для consistency:

- Меню локация: kebab → Diagnostics → "Экспорт конфига" / "Import
  config" — рядом с "Сбросить настройки" логически (resilience-related).
- Desktop, когда добавим, повторит ту же location: MainWindow kebab →
  Settings → "Импорт / Экспорт" pair.

QR — Android-only bonus, на desktop не маскимально полезно (нет камеры
у большинства desktop'ов; QR-display через WebCam scan — нишевый use
case).

## Fix strategy

### Phase 1: Core — schema + validation

**File**: `VPNRouter.Core/Services/ConfigShareDocument.cs`

```csharp
public sealed class ConfigShareDocument
{
    public const int CurrentVersion = 1;
    public const string Schema = "vpnrouter-config-share";

    public int Version { get; set; } = CurrentVersion;
    public DateTimeOffset ExportedAt { get; set; }
    public ExportedFrom ExportedFrom { get; set; } = new();
    public string ConfigMode { get; set; } = "subscribe";
    public List<SubscriptionEntry> Subscriptions { get; set; } = new();
    public string? ManualVlessUri { get; set; }
    public CustomConfigPayload? CustomConfig { get; set; }
    public ExportedSettings? Settings { get; set; }
    public PerAppFilterExport? PerAppFilter { get; set; }

    public static string Serialize(ConfigShareDocument doc) { /* JsonConvert */ }
    public static ConfigShareDocumentParseResult TryParse(string json) { /* validate */ }
}
```

Result type `ConfigShareDocumentParseResult` carries either `Document` or
`ErrorMessage` (mirrors `Try*` pattern from Core).

### Phase 2: QR encoder vendor

**File**: `VPNRouter.Core/Services/QrCode.cs` (~600 LOC, pure C#).
Returns `QrCodeMatrix(bool[,] modules)`. No external deps.

Source: Project Nayuki QR Code Generator (BSD-2 license). Single-file C#
adaptation. Tests: encode known string → matrix size + module count
matches the published reference data.

### Phase 3: Android storage adapter

**File**: `VPNRouter.Android/AndroidConfigShare.cs`

```csharp
public static class AndroidConfigShare
{
    public static ConfigShareDocument BuildSnapshot(
        bool includeSettings, bool includePerApp);

    public static (bool ok, string? error) ApplySnapshot(
        ConfigShareDocument doc, bool applySettings, bool applyPerApp);

    public static string BackupCurrentState(); // returns backup file path
}
```

### Phase 4: MainActivity intent integration

`MainActivity.cs`:
- `RequestExport(string suggestedFileName, string jsonContent)` →
  ACTION_CREATE_DOCUMENT, holds pending JSON in static field. OnActivityResult
  writes via ContentResolver.OpenOutputStream.
- `RequestImport()` → ACTION_OPEN_DOCUMENT.
  OnActivityResult reads via ContentResolver.OpenInputStream → invokes
  static callback in AndroidApp to surface confirm dialog.

### Phase 5: AndroidApp UI

Kebab menu — add to existing Diagnostics section:
- "Экспорт конфига" / "Export config"
- "Импорт конфига" / "Import config"

Each opens a tiny inline overlay (Border layered above ScrollViewer like
log viewer / settings overlay):

**Export overlay**:
- Title "Экспорт конфига"
- Checkboxes:
  - [ ] Включить настройки (тема, язык, маршрутизация)
  - [ ] Включить per-app фильтр
- Banner: "VLESS URI / token — не делитесь в открытых каналах"
- Кнопка "Сохранить"

**Import overlay**:
- Title "Импорт конфига"
- Подсказка "Выберите файл .json"
- Кнопка "Выбрать файл" → triggers ACTION_OPEN_DOCUMENT
- После pick — preview: "Подписки: 2, Серверы: 17, Custom JSON: нет"
- Confirmation: "Импорт перезапишет текущие подписки. Продолжить?"
  - Кнопка "Импортировать"
  - Кнопка "Отмена"

**QR overlay** (new — replaces handbook §3.4 placeholder):
- Title "Поделиться VLESS"
- Текущий active server (label + endpoint)
- QR-код 280×280
- Кнопка "Скопировать URI"
- Текстовое поле для paste-from-clipboard
- Кнопка "Вставить и подключить"
- Banner: "URI = пароль; делитесь только лично"
- Кнопка "Закрыть"

### Phase 7: Tests

`VPNRouter.Tests/ConfigShareDocumentTests.cs`:
1. Roundtrip — Build → Serialize → TryParse → проверить что Schema +
   Version + Subscriptions[0].Url match.
2. Invalid JSON → TryParse returns error, Document=null.
3. Wrong schema field → error.
4. Old version → error (forward-compat check; bumped from 1 to 2 future
   doc would be rejected).
5. Опт-айн поля null → не падаем.
6. Manual URI mode без subscriptions[] → парсится OK.
7. Custom config mode без subscriptions[] → парсится OK.
8. Опт-ин Settings полностью заполнены → roundtrip preserves all.
9. PerAppFilter с пустыми packages → preserves.
10. QrCode — encode "vless://..." → matrix size match expected for
    medium-error-correction QR.

- ~3-4 часа реализация (Core + Android + tests + localization).
- ~1 час live phone test cycle.

  Framework intent flow has Android version quirks (ACTION_OPEN_DOCUMENT
  on API 19+ — universal на нашем минимуме API 23).
