# VPNRouter - local DSH overlay

- Keep roadmaps, task briefs, outcomes, and durable working notes under `plans/`.
- In this checkout, `origin` is the canonical GitHub repository. Push only the current task branch with `git push -u origin HEAD`; never push directly to protected `main`.
- Do not add, rename, or rewrite remotes automatically. Forgejo is a post-acceptance mirror described in `docs/agent-contract.md`, not the primary development remote.
- Candidate releases, stable cuts, deployments, tags, and merges always require explicit owner authorization. A green build or verification result is evidence, not authority.
- Use `docs/test-workers.md` for current worker aliases and resource rules. Do not copy volatile IPs, credentials, or dated capacity figures into other active instructions.
